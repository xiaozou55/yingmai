关于影脉

影脉是一个影视人物合作关系与作品发现平台。它把公开的电影元数据与演职员记录整理成 「人物—作品」网络，再据此分析共同参与关系，为用户提供人物检索、关系探索与作品发现。

平台中的「合作」仅指共同参与作品，不代表私人友谊、直接对手戏或实际交流。 每一条关系都可以追溯到具体的作品和来源。

数据来源与署名

本平台使用 TMDB 公开接口数据。依据 TMDB 的使用要求，特此声明：

This product uses the TMDB API but is not endorsed or certified by TMDB.

数据接口：movie credits 与 person combined credits。 非商业用途；商业用途须另行取得许可。

样本范围声明

  • 仅电影，不包含电视剧、综艺。接口会同时返回电视剧记录，已在采集阶段过滤。
  • 仅华语片，即 TMDB 中 original_language 为 zh（国语）或 cn（粤语）的影片。TMDB 用 cn 标注粤语片，并非标准语言码。
  • 以八位跨代际演员为种子（成龙、洪金宝、刘德华、梁朝伟、张曼玉、周星驰、吴京、易烊千玺） 选取其作品全集，再按「稠密优先 + 热度补足」取 200 部。
  • 图谱节点按每部电影前 10 位主演加导演取样，其余演职员保留明细但不参与关系计算。
  • 年份按发行年统计，不代表实际拍摄时间。

因此：某位人物的网络指标只反映当前样本内的情况，不代表其在行业中的地位； 路径查找「未找到」只表示当前样本与条件下没有找到，不代表现实中无关联。

计算规则

  • 人物与电影按 TMDB 源 ID 关联，姓名只作展示与检索，不因重名合并。
  • 同一人在同一部电影中担任多个职务时保留明细，但每对人物每部电影只计一次。
  • 合作边为无向边，频次为共同出演的电影数，排除自连接。
  • 推荐基于合作者与类型偏好生成，不生成事实关系；缺少中文名称时回退原名，不猜测翻译。
